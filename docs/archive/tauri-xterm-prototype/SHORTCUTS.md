# WinTerminal++ 快捷键

当前 MVP 使用固定的 tmux 风格 Prefix：先按 `Ctrl+B`，松开后再按第二个键。Prefix 在 1.8 秒后自动取消，按 `Escape` 可以立即取消。

| 操作 | 默认快捷键 |
|---|---|
| 向左、右、上、下选择窗格 | `Ctrl+B`，然后按方向键 |
| 向左、右、上、下创建窗格 | `Ctrl+B`，然后按 `Shift+方向键` |
| 向左、右、上、下扩大活动窗格 | `Ctrl+B`，然后按 `Ctrl+方向键` |
| 新建标签页 | `Ctrl+B`，然后按 `C` |
| 下一个标签页 | `Ctrl+B`，然后按 `N` |
| 上一个标签页 | `Ctrl+B`，然后按 `P` |
| 跳到第 0–9 个标签页 | `Ctrl+B`，然后按 `0`–`9` |
| 关闭活动窗格 | `Ctrl+B`，然后按 `X` |
| 最大化或恢复活动窗格 | `Ctrl+B`，然后按 `Z` |
| 取消 Prefix | `Escape` |

窗格工具栏同时提供四向分割、最大化、关闭和进程重启按钮。

当前迭代只实现固定键位。快捷键编辑、冲突检测和持久化属于后续配置里程碑，不能将其描述为已交付。
